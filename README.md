# NEXORA — The Digital Playground

A responsive, neon-dark concept website built with plain HTML, CSS, and JavaScript. No framework or build step is required.

## Preview
Open `index.html` in a browser. Keep the `css` and `js` folders alongside it.

## Included interactions
- Responsive mobile navigation
- Animated starfield and reveal-on-scroll sections
- Hover spotlight and tilt effects on interactive cards
- Clickable energy orb
- Interactive color lab with swatches and random color button
- Reaction-time mini-game with a locally saved best score
- Project category filters
- Keyboard-accessible project cards and project detail modal
- Reduced-motion accessibility support

## Notes
- Google Fonts are loaded from the internet; system fallback fonts are provided.
- The contact button opens a prefilled email draft to `hello@nexora.example`, which is a placeholder address. Replace it in `index.html` with your real contact address before publishing.
- This is a front-end concept. It does not require an API or backend.
